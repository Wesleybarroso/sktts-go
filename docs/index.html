SKTTS-Go API

API de Text-to-Speech para transformar texto em áudio utilizando o motor Piper, com autenticação por API Key, planos, quotas, rate limiting e controle de concorrência.

Autenticação

Os endpoints protegidos utilizam uma API Key enviada através do header X-API-Key. 

X-API-Key: SUA_API_KEY
Nunca coloque sua API Key diretamente em código frontend público. Para aplicações web, faça a chamada através do seu backend.

Primeiro request

O endpoint principal é POST /tts. O corpo da requisição utiliza parâmetros de formulário. 

curl -X POST https://SEU-DOMINIO/tts \
  -H "X-API-Key: SUA_API_KEY" \
  --data-urlencode "text=Olá, este é um teste." \
  --data-urlencode "format=ogg" \
  --data-urlencode "language=pt-BR" \
  --data-urlencode "voice=Cadu" \
  --output audio.ogg

Text-to-Speech

POST /tts

Converte texto em áudio utilizando uma das vozes disponíveis.

Headers

Header Obrigatório
X-API-Key Sim

Parâmetros

Parâmetro Obrigatório Descrição
text Sim Texto que será convertido em áudio.
format Sim Formato do áudio.
language Não Idioma da voz: pt-BR, en-US ou es-ES.
voice Não Voz utilizada na síntese.

Exemplo

curl -X POST https://SEU-DOMINIO/tts \
  -H "X-API-Key: SUA_API_KEY" \
  --data-urlencode "text=Olá, seja bem-vindo à SKTTS-Go." \
  --data-urlencode "format=ogg" \
  --data-urlencode "language=pt-BR" \
  --data-urlencode "voice=Cadu" \
  --output audio.ogg
O endpoint /tts atualmente recebe os parâmetros como formulário. Não envie JSON diretamente para esse endpoint.

Administração · API Keys

Os endpoints administrativos exigem uma credencial administrativa. Eles não devem ser utilizados diretamente por aplicações cliente.

POST /admin/keys

Cria uma nova API Key.

curl -X POST https://SEU-DOMINIO/admin/keys \
  -H "X-API-Key: SUA_ADMIN_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Meu cliente",
    "key_type": "client",
    "plan": "free_30d"
  }'
GET /admin/keys

Lista as API Keys cadastradas.

curl https://SEU-DOMINIO/admin/keys \
  -H "X-API-Key: SUA_ADMIN_KEY"
GET /admin/keys/{id}

Obtém uma API Key específica.

curl https://SEU-DOMINIO/admin/keys/ID \
  -H "X-API-Key: SUA_ADMIN_KEY"
POST /admin/keys/{id}/suspend

Suspende uma API Key.

POST /admin/keys/{id}/activate

Ativa novamente uma API Key suspensa.

POST /admin/keys/{id}/revoke

Revoga uma API Key.

DELETE /admin/keys/{id}

Remove uma API Key.

Administração · Planos

POST /admin/plans

Cria um plano.

curl -X POST https://SEU-DOMINIO/admin/plans \
  -H "X-API-Key: SUA_ADMIN_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "pro",
    "name": "Pro",
    "description": "Plano profissional",
    "price": 29.90,
    "requests_per_minute": 30,
    "requests_per_day": 1000,
    "characters_per_request": 10000,
    "characters_per_day": 100000,
    "max_concurrent_tts": 5,
    "status": "active"
  }'
GET /admin/plans

Lista os planos cadastrados.

curl https://SEU-DOMINIO/admin/plans \
  -H "X-API-Key: SUA_ADMIN_KEY"
GET /admin/plans/{id}

Consulta um plano específico.

PUT /admin/plans/{id}

Atualiza um plano existente.

DELETE /admin/plans/{id}

Remove um plano.

Exemplos de integração

JavaScript

const form = new URLSearchParams();

form.append("text", "Olá! Este áudio foi gerado pela SKTTS-Go.");
form.append("format", "mp3");
form.append("voice", "Wesley");

const response = await fetch(
  "https://SEU-DOMINIO/tts",
  {
    method: "POST",
    headers: {
      "X-API-Key": "SUA_API_KEY"
    },
    body: form
  }
);

const audio = await response.blob();

const url = URL.createObjectURL(audio);

const player = new Audio(url);

await player.play();

Python

import requests

response = requests.post(
    "https://SEU-DOMINIO/tts",
    headers={
        "X-API-Key": "SUA_API_KEY"
    },
    data={
        "text": "Olá! Este áudio foi gerado pela SKTTS-Go.",
        "format": "mp3",
        "voice": "Wesley"
    }
)

response.raise_for_status()

with open("audio.mp3", "wb") as file:
    file.write(response.content)

Node.js

const form = new URLSearchParams({
  text: "Olá! Testando a SKTTS-Go.",
  format: "ogg",
  voice: "Wesley"
});

const response = await fetch(
  "https://SEU-DOMINIO/tts",
  {
    method: "POST",
    headers: {
      "X-API-Key": process.env.SKTTS_API_KEY,
      "Content-Type": "application/x-www-form-urlencoded"
    },
    body: form
  }
);

const buffer = Buffer.from(await response.arrayBuffer());
